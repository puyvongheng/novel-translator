# 🎬 CapCut-Style AI Khmer Movie Studio & Speech Studio
### ឧបករណ៍បកប្រែរឿងជាភាសាខ្មែរ + Tab បំប្លែងអត្ថបទទៅជាសំឡេងនិយាយ (TTS) និង Export MP3

---

## 🌟 ផ្ទាំងការងារទាំងពីរ (2 Main Tabs):

### 🎬 Tab 1: Movie Translator & CC Studio (បកប្រែរឿង)
- **CapCut-Style Video Player & Timeline**: ចាក់វីដេអូផ្ទាល់ អូស Playhead មើលនាទី/វិនាទី និងមាន CC Overlay រត់លើអេក្រង់។
- **AI Speech-to-Text**: ចាប់សំឡេងនិយាយក្នុងរឿង (ចិន, អង់គ្លេស...) ស្វ័យប្រវត្តិជាមួយ Whisper AI។
- **Translation Modes (Free & API)**:
  - `Google (Free / មិនអស់លុយ)`: ដំណើរការលឿន មិនជាប់ Limit និងឥតគិតថ្លៃ 100%។
  - `Gemini / Google AI (API Key)`: អាចបញ្ចូល API Key របស់អ្នកផ្ទាល់ ឬកំណត់តាមរយៈ Environment Variable (`GEMINI_API_KEY`)។
  - `OpenAI ChatGPT (API Key) & MyMemory (Free)`។
- **CC to Khmer Dubbing**: បង្កើតសំឡេងនិយាយខ្មែរដាក់ត្រូវតាមវិនាទីនៃរឿង (Piseth / Sreymom)។
- **Export**: Save .SRT, Burn CC ចូល MP4, ឬ Export រឿងពេញលេញដែលមានទាំងសំឡេងខ្មែរ និង CC។

---

### 🎙️ Tab 2: Text-to-Speech & Export MP3 (បំប្លែងអត្ថបទជាសំឡេង & Export MP3)
- **ងាយស្រួលប្រើបំផុត**: គ្រាន់តែវាយ ឬ Paste អត្ថបទ (ភាសាខ្មែរ ឬភាសាផ្សេងៗ) ចូលក្នុងប្រអប់។
- **ជម្រើសសំឡេង**:
  - 👨 `Piseth (Male / ប្រុស)`
  - 👩 `Sreymom (Female / ស្រី)`
- **ល្បឿននិយាយ (Speed Rate)**: ធម្មតា (+0%), លឿន (+15%), យឺត (-15%), ឬ លឿនខ្លាំង (+30%)។
- **🔊 ស្ដាប់សំឡេង (Speak Now)**: ចុចស្ដាប់សំឡេងនិយាយភ្លាមៗក្នុងកម្មវិធី (មានប៊ូតុង Stop)។
- **💾 Export to MP3 File**: ចុចតែមួយ Click ដើម្បីទាញយកជាឯកសារ Audio `.mp3` រក្សាទុកក្នុងកុំព្យូទ័ររបស់អ្នក!
